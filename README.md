# Diario Personal

Proyecto desarrollado para la Evaluación 1 de Backend con Python y Django.

## Descripción

Diario Personal es una aplicación desarrollada en Django que tiene como propósito
digitalizar y centralizar la gestión de entradas personales.

En esta primera etapa se implementa la estructura inicial del proyecto, una
página de bienvenida, rutas propias de la aplicación y una página de error
404 personalizada.

## Requisitos

- Python
- Django

Las dependencias utilizadas se encuentran registradas en el archivo
`requirements.txt`.
